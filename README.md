# ShiftWallet v3.0

GitHub Pagesで公開できるiPhone/Android対応PWAです。v2/v2.2のデータは初回起動時に自動移行します。

## 今回の主要変更

- 「勤務済み」機能を廃止。現在の月収は「今日までに登録されているシフト」から自動計算。
- ホームに「今月の予定月収」「現在の月収」を表示。
- 同じ日に複数シフトを登録可能。一括追加でも既存シフトがある日へ追加可能。
- プリセットの休憩時間を通常追加・ワンタップ追加・一括追加すべてに確実に引き継ぐよう修正。
- カレンダーの日付タップで、その日のシフト一覧・編集・削除・追加。
- 翌週コピー、4週コピー、前月コピー。
- 勤務先/プリセット色分け、日別給与表示、勤務時間集計、目標用シフト候補。
- 時給履歴、締め日/給料日、給与端数処理、自動休憩、交通費方式、深夜/残業/早朝/土日/1勤務手当。
- 給与明細の総支給・手取り・控除・実質時給。
- 口座/現金/電子マネー、振替、クレジットカード、請求予測、臨時収入。
- 固定費/サブスク、価格履歴、年額表示、支払アラート。
- 支出テンプレート、履歴から再入力、レシート写真添付。
- 複数貯金目標、達成予定、最低残高、1日あたり使える金額。
- 買い物シミュレーター、30/60/90日残高予測。
- 年間収入予測・任意警告ライン、勤務先別分析、月間/年間レポート。
- 入出金カレンダー、検索、ダークモード、テーマ色、ホームカード表示/並び替え。
- 毎日1回の端末内自動バックアップ、JSON/CSV。

## PWA版の制約

- レシート写真の添付はできますが、OCRによる自動読み取りは未搭載です。
- 自動バックアップは端末内(localStorage)です。iCloud等への自動同期にはネイティブアプリ化が必要です。
- iPhoneホーム画面の本物のWidgetKitウィジェットはPWAでは作れません。
