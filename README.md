# ShiftWallet v2.1

GitHub Pagesで動作する、シフト・給与・家計簿を一体化したPWAです。

## v2で追加した15機能

1. 締め日・給料日を勤務先ごとに自由設定
2. 複数勤務先
3. 時給変更履歴
4. シフトの予定 / 実績を分離
5. 深夜・残業・交通費の見込み計算
6. 期間・曜日を指定したシフト一括追加
7. 次回給料日と対象期間、次回給与見込み
8. 給与目標から必要シフト回数を逆算
9. 固定費・サブスク（月額 / 年額）
10. カテゴリ別月予算
11. 次回給料日まで使える金額の目安
12. 60日間の未来残高予測
13. 給与・勤務時間・支出の6か月グラフ
14. 給与明細の実額とアプリ予測の差額チェック
15. JSON完全バックアップ + CSV書き出し

## 初期設定例：10日締め・25日給料日

設定 → 勤務先・給与サイクル → 編集 で以下にします。

- 締め日: 10日
- 給料日: 25日
- 支払いタイミング: 締め月の給料日

この場合、例として 8/11〜9/10 の勤務分を 9/25 の給与として集計します。

## GitHub Pages更新

既存リポジトリのルートに、次のファイルを上書きアップロードします。

- index.html
- app.js
- styles.css
- manifest.webmanifest
- sw.js
- README.md（任意）

`icons` フォルダはv1のものをそのまま使えます。

GitHub Pagesは Settings → Pages → Deploy from a branch → main / (root) のままでOKです。

## データ

データはブラウザの localStorage に保存します。v1のデータが同じブラウザに残っている場合、初回起動時にv2へ自動移行します。更新前にJSONバックアップを推奨します。

## 注意

- 給与は見込み計算です。勤務先の丸め規則、休憩の取得時刻、独自手当、税・控除などで給与明細と差が出る場合があります。
- 深夜・残業の割増は勤務先設定の倍率を使い、重なる時間帯は両方の割増を加算します。
- 給料日の「土日調整」は対応しますが、日本の祝日判定はオフライン版では自動化していません。
