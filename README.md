# ShiftWallet Simple v4.5

v4.4 のシンプルな構成を維持したまま、カレンダーの「今日」の黒丸とシフトラベルが重ならないように調整した版です。

## v4.5 の修正
- 今日の日付の黒丸を日付専用の領域に固定
- A班・B班などのシフトラベルは、その下の専用領域へ表示
- 同日に複数シフトがある場合も、黒丸とシフトラベルが重ならない
- 小さいiPhone幅でも日付とシフト表示が干渉しにくいように調整

## 継続仕様
- 今月の勤務時間（現在 / 予定）
- 目標月収までプリセットごとの「あと○回」
- 日付タップでシフト編集・削除
- シフト追加モードの誤操作防止
- 月収の前月比
- 勤務先・シフトプリセットごとの色分け
- 勤務先ごとの時給・締め日・給料日
- シフト終了時点で現在の月収へ反映
- 固定費差引後の月収表示
- 掛け持ち・同日複数シフト対応
