# ShiftWallet Simple v4.4

シンプルさを維持したまま、シフト把握に必要な機能だけを追加した版です。

## v4.4 の追加
- **今月の勤務時間**: 現在まで終了した勤務時間と、締め期間内の予定勤務時間をホームに表示
- **プリセットごとの「あと○回」**: 目標月収まで、各シフトプリセットならあと何回必要かを一覧表示
- **日付タップで編集・削除**: プリセット未選択時に日付をタップすると、その日のシフト一覧から編集・削除可能
- **追加モードの誤操作防止**: プリセット選択中は「追加モード」を明示し、前後月の薄い日付への誤追加を防止
- **月収の前月比**: 今月の予定月収と、各勤務先の1つ前の締め期間の給与合計を比較
- **シフトの色分け**: 勤務先とプリセットに落ち着いた色を自動割り当て。カレンダーには最大3件まで色付きの短いラベルを表示し、同日に複数シフトがあっても判別しやすくしました。

## 継続仕様
- 勤務先ごとに時給・締め日・給料日を設定
- 現在の月収はシフト終了時刻を過ぎた時点で反映
- 今月の月収は締め期間内の予定シフトを含む
- 毎月の固定費を差し引いた金額を表示
- 複数バイト先・同日複数シフト対応
- プリセットには勤務先・時間・休憩時間を保存
- 月が変わると左上の年月を自動更新
