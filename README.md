# ShiftWallet Simple v4.10

シンプルなシフト・給与管理PWAです。

## v4.10 変更

- iPhoneなど狭い画面で単発シフト追加ダイアログの「日付」「終了時刻」等が右にはみ出す問題を修正
- 日付・時刻入力を含むフォーム要素をダイアログ幅内に必ず収めるレスポンシブ調整を追加

- シフトプリセットを作っていなくても、カレンダーの日付タップから単発シフトを追加できます。
- 単発シフトの追加時は以下を入力します。
  - バイト先
  - 勤務時間（開始・終了）
  - 時給
  - 休憩時間
- 日付から追加した単発シフトはシフトプリセットには保存されません。
- すでにシフトが入っている日をタップした場合は、その日の一覧から編集・削除、または「この日にシフトを追加」ができます。
- 単発シフトの時給は、そのシフト固有の時給として給与計算に反映します。
- シフト画面に「週ごとの勤務時間」を追加しました。カレンダーと同じ日曜〜土曜単位で、休憩を引いた勤務時間を表示します。
- 現在の週には「今週」と表示します。

## 継続している主な仕様

- プリセットを選択している場合は、従来どおり日付をワンタップしてシフトを追加できます。
- 同じ日に複数のシフトを登録できます。
- カレンダー内のシフト名は最大5文字まで表示します。
- 現在の月収はシフト終了時刻を過ぎた時点で反映します。
- 勤務先ごとの締め日・給料日を給与計算に反映します。
- 目標月収、固定費、掛け持ちバイトに対応します。

## 更新方法

GitHub Pagesの既存リポジトリで `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `README.md` を上書きしてください。`icons` は変更不要です。
