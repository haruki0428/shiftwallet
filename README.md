# ShiftWallet Simple v4.8

シンプルなシフト・給与管理PWAです。


## v4.8 変更

- カレンダー内のシフトプリセット名を最大5文字まで表示
- `B班 男` のように空白を含む名前も、そのまま5文字以内で表示
- 複数シフトがある日はラベルを縦に並べ、セル幅を押し広げないよう調整

## v4.7 追加機能

- 目標月収が1円以上設定されている場合、登録した給料日にアプリを開くと「給料日レポート」を表示します。
- その月に支給される給与を、勤務先ごとの締め日・給料日から自動で集計します。
- 複数のバイト先がある場合は、その月に支給される給与を全勤務先分合算して目標月収と比較します。
- 達成時: 「目標月収を達成しました。」
- 未達時: 目標までの残額、シフトプリセットを基準にした追加シフト回数、給与計算期間に対する「平均して週に＋何日必要だったか」を表示します。
- 必要回数の基準プリセットは、その給与計算期間で最もよく使ったプリセットを優先します。履歴がない場合は利用可能なプリセットから算出します。
- 同じ内容のレポートは同じ給料日に何度も表示しません。目標額や給与額が変わった場合は再表示されます。
- 目標月収が0円の場合はレポートを表示しません。

## v4.6 から継続している修正

- カレンダーは日付とシフトを2段構造にし、今日の黒丸とA班/B班などのラベルが重ならないようにしています。

## 更新方法

GitHub Pagesの既存リポジトリで `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `README.md` を上書きしてください。`icons` は変更不要です。
