# ShiftWallet Simple v4.6

シンプルなシフト・給与管理PWAです。

## v4.6 の修正

- カレンダーの各日を「日付」と「シフト」の2段グリッドに変更
- 日付とA班/B班などのシフトラベルを別レイアウト領域に分離
- 今日の黒丸とシフトラベルが重ならないよう修正
- 通常の日付でもシフトラベルが数字へ被らないよう修正
- 小さい画面でも日付行を固定し、その下にシフトを表示

## 更新方法

GitHub Pagesの既存リポジトリで `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `README.md` を上書きしてください。`icons` は変更不要です。
