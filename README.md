# ShiftWallet Simple v4.2

シフト管理・月収・固定費に絞ったシンプル版です。v4.2では「次回給与見込み」の独立表示をなくし、勤務先ごとの締め日・給料日を「現在の月収」「今月の月収」へ直接反映しました。

## ホームの月収表示
- **現在の月収**: 各勤務先の現在の締め期間について、今日までに登録されているシフト分を合計
- **今月の月収**: 各勤務先の現在の締め期間について、締め日までに登録されている予定シフト分を合計
- 両方とも毎月の固定費を差し引いた金額を併記
- 各金額の下に、勤務先ごとの給与内訳を表示
- 内訳には締め日・給料日・対象期間をコンパクトに表示

### 例: 10日締め・25日給料
8/28時点では現在の給与期間を **8/11〜9/10** と判定します。
- 現在の月収: 8/11〜8/28までの登録シフト
- 今月の月収: 8/11〜9/10までの登録シフト予定
- 支給日: 9/25

掛け持ちの場合は、勤務先ごとにそれぞれの締め日・給料日から給与期間を計算し、合計額と内訳を表示します。

## 継続仕様
- 複数バイト先対応
- 勤務先ごとに名前・時給・締め日・給料日を設定
- プリセットごとに勤務先・開始・終了・休憩時間を保存
- プリセットを選択してカレンダーの日付をタップするだけでシフト追加
- 同じ日に複数の異なるシフトを登録可能
- 固定費は毎月同額として月収から差し引き
- 月収目標は「今月の月収」と比較し、指定プリセットであと何回・何時間必要かを計算
- 画面左上の年月は端末日付を基準に自動更新
- v4.1までの保存データをそのまま利用
