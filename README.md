# ShiftWallet v2

GitHub Pagesで公開できる、iPhone/Androidホーム画面追加対応PWAです。

## v2 主な機能

1. 締め日・給料日を勤務先ごとに自由設定（月末、当月/翌月/翌々月、土日調整）
2. 複数勤務先
3. 時給変更履歴
4. シフト予定/実績
5. 深夜・残業・交通費の給与概算
6. シフト一括追加
7. 次回給料見込み
8. 給与目標から必要シフト回数を逆算
9. 固定費・サブスク（月払い/年払い）
10. カテゴリ別予算
11. 次回給料まで使える金額
12. 未来の残高予測
13. 給与・勤務時間・支出グラフ
14. 給与明細との差額確認
15. JSON完全バックアップ + CSV書き出し

## 既存v1からの更新

同じGitHub Pages URLで `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js` を上書きすれば更新できます。`icons` は変更不要です。

v1のブラウザ内データは、初回起動時に可能な範囲でv2へ自動移行します。更新前にv1の「JSON書き出し」を行うことを推奨します。

## 10日締め・25日払いの設定例

設定 → 勤務先 → 編集
- 締め日: 10日
- 給料日: 25日
- 給料のタイミング: 締め月の当月

この場合、8/11〜9/10勤務分が9/25の給与として集計されます。

## 注意

- 給与額は概算です。勤務先独自の端数処理、法定休日、週40時間超、税・社会保険、各種手当などは給与明細と一致しない場合があります。
- 「土日なら前/次の平日」は土日のみを判定し、日本の祝日カレンダーはオフライン仕様のため判定しません。
- データは端末のブラウザ内(localStorage)に保存されます。定期的にJSONバックアップを保存してください。
