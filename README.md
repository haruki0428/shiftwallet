# ShiftWallet Simple v4.1

シフト管理・月収・固定費に絞ったシンプル版です。v4.1では勤務先ごとの締め日・給料日と次回給与見込みを追加しました。

## 画面
- ホーム: 現在の月収 / 今月の予定月収 / それぞれの固定費差引後 / 次回給与見込み / 月収目標
- シフト: プリセットを選択 → カレンダーの日付をタップで即追加
- 設定: 月収目標 / 固定費 / バイト先 / シフトプリセット

## v4.1 追加
- バイト先ごとに締め日（1〜31日）と給料日（1〜31日）を設定
- ホームに勤務先ごとの「次回給与見込み」を表示
- 給料日が締め日より後なら締め月と同じ月、同日以前なら翌月支給として自動判定
- 31日は2月など短い月では月末として計算
- 例: 10日締め・25日払い → 8/11〜9/10勤務分を9/25の給与見込みとして表示
- 例: 月末締め・15日払い → 8/1〜8/31勤務分を9/15の給与見込みとして表示
- 画面左上の年月は端末の日付から表示し、月をまたいだままアプリを開いていてもフォーカス復帰・バックグラウンド復帰・1分ごとの確認で自動更新

## 継続仕様
- 複数のバイト先に対応
- バイト先ごとに名前・時給を登録
- プリセットごとに勤務先・開始・終了・休憩時間を登録
- 同じ日に複数の異なるシフトを登録可能
- 同じプリセットの誤ダブルタップは重複防止
- 「現在の月収」は当月の今日までに登録されたシフトで計算
- 「予定月収」は当月に登録された全シフトで計算
- 固定費は毎月同額の項目として合計し、両方の月収から差し引いて表示
- 月収目標は予定月収との差額を表示し、指定プリセットならあと何回・何時間必要かを計算
- v4.0の保存データは同じ保存領域を使い、そのまま継続。締め日・給料日が未設定の既存勤務先には初期値として10日・25日を補完
